Technical Principles
  • ASGI Coexistence: Two independent MCP servers mounted on a single FastAPI instance.
  • Domain Isolation: Playwright restricted to browser tasks; Standard handles pure API logic.
  • Tool Mirroring: Real-time metadata sync ensures feature parity across protocols.

Runtime Execution

Tool Invocation Flow

sequenceDiagram
    participant Agent
    participant Client as "MCPToolClient"
    participant MCPServer as "MCP Server"
    participant Tool as "Business Logic"
    participant DB as "PostgreSQL"

    Agent->>Client: call_tool_async("search_products", args)

    alt Local Detection
        Client->>MCPServer: Direct In-Memory Call
        MCPServer->>Tool: execute()
        Tool->>DB: query session
        Tool->>Tool: search pipeline
        Tool-->>MCPServer: result
        MCPServer-->>Client: TextContent
    else Remote Route
        Client->>Client: HTTP POST /standard/call
    end

    Client->>Client: _parse_parts_to_dict()
    Client-->>Agent: {status, result}
Performance Optimization
  • In-Process Routing: Local MCP servers are called directly via Python functions to bypass the HTTP stack.
  • Typed Output: Automatic conversion from CallToolResult to native Python dictionaries.
  • Graceful Fallbacks: Support for JSON, AST literal evaluation, and raw string parsing.

Resilience Pattern
  • CDP Port 9222: Attempts to attach to an already running Chrome to preserve active cookies.
  • Login Wall Timeout: Waits up to 120s for manual user login if automated detection fails.
  • Multi-Selector Fallback: Heuristic-based element finding for dynamic eBay HTML structures.

State Synchronization

Startup Engine

sequenceDiagram
    participant Lifespan
    participant Std as "Standard MCP"
    participant PW as "Playwright MCP"

    Lifespan->>Std: configure_mcp()
    Lifespan->>PW: configure_playwright_mcp()
    
    PW->>Std: inspect tools catalog
    
    loop Each Tool
        Std-->>PW: Tool definition
        PW->>PW: Mirror tool metadata
    end
    
    Note over PW: Standard tools now visible via Playwright port
Mirroring Strategy
  • Atomic Lifespan: All sync operations complete before the FastAPI server accepts traffic.
  • Identity Preservation: Synced tools keep their original names for seamless Agent planning.
  • Entity Coverage: Includes Tools, Prompts, and Resources (like profile://).
