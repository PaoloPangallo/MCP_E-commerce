Concurrency Control

Managed via an async semaphore at /agent/stream. Limits concurrent heavy LLM workloads to prevent memory exhaustion and Redis timeouts.

ReAct Reasoning Step

Recursive loop with a depth of 6. Each turn extracts vision signals (if images are present) and hydrates state from the Redis LTM.

Intelligent Caching

Semantic hash-based caching in Redis. If a similar query exists within the TTL, the system returns a pre-ranked response, bypassing external API latency.

Reranking Signals

Combines semantic cosine similarity with eBay metadata (Seller Trust, Shipping) and RAG "Product Expert" insights for the final hybrid score.

Zero-latency Routing

The client detects if the target MCP server is running in the same process (Local Mode) and executes it directly, avoiding the network stack entirely.

Content Normalization

Transforms raw CallToolResult (Text/JSON/Images) into a sanitized Python dictionary that is compatible with the Agent's Observation structure.

Sentiment Analysis

Performs RAG-enhanced sentiment analysis on the last 50 text reviews of a seller to identify hidden risks (e.g., "slow shipping" vs "damaged goods").

Trust Logic

Combines feedback percentage, registration date, and recent sales volume with NLP sentiments to calculate a 0-100 Trust Score.

Exponential Moving Average

Uses an EMA decay algorithm (α=0.20) to track user budget preferences and category affinities, prioritizing recent searches over historical data.

Shadow Profiling

Asynchronous profiling runs after every successful search, updating the user's permanent model without blocking the response flow.
