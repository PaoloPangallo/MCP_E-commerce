Semantic Vectorization

Uses the all-MiniLM-L6-v2 model to convert natural language queries into 384-dimensional dense vectors for high-speed similarity search.

Contextual RAG

Retrieves "Expert Feedback" and "Trusted Seller" metadata from Qdrant to enrich the reranking context with domain-specific knowledge.

Auto-Learning

The system monitors search patterns to infer preferences (e.g., 'New' vs 'Used') without requiring manual settings from the user.

Contextual Injection

Learned attributes are prefixed with auto_ in the database and injected into every Agent turn to guide the LLM's reasoning.

Integration Logic

Manual vs Auto

Manual Overrides

Settings explicitly defined in the profile UI take strict precedence over learned behaviors to ensure user agency.

Shadow Profiling

The profiling engine runs in "shadow mode" for each interaction, refining the long-term memory (LTM) without slowing down the UI.
