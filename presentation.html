Il Problema & La Soluzione

😓

Il Problema

  • Ricerca manuale e lenta su eBay
  • Venditori inaffidabili difficili da identificare
  • Prezzi fuori mercato non evidenti
  • Nessuna personalizzazione sui risultati
  • Difficile confrontare più prodotti contemporaneamente
🚀

La Soluzione

  • Ricerca in linguaggio naturale (italiano)
  • Trust score automatico per ogni venditore
  • Rilevazione anomalie di prezzo con Z-score
  • Apprendimento delle preferenze utente
  • Confronto intelligente multi-prodotto

Features Chiave

🔤

NLP Italiano

spaCy con modello italiano, fuzzy brand matching, query expansion e parsing LLM-enhanced per estrarre brand, prezzo e condizione.

👤

User Profiling

Apprendimento automatico di affinità categorie, budget contestuali (EMA), preferenza condizione e profondità interazione.

📈

Price Tracking

Background task che monitora la wishlist e rileva variazioni di prezzo. Storico prezzi per item con endpoint dedicato.

👁️

Vision Analysis

Upload immagine prodotto → Gemini Vision estrae brand, tipo prodotto e clue di condizione per arricchire la ricerca.

⭐

Wishlist Sync

Sincronizzazione bidirezionale con eBay watchlist. Aggiunta async al salvataggio, rimozione esplicita supportata.

🤝

Seller Trust

Score calcolato su feedback recency + volume + positività. Sentiment NLP sui commenti. Cache 2h per venditori.

API Endpoints

Metodo Percorso Descrizione
POST /agent/stream Agente AI in streaming SSE (query → risposta in tempo reale)
POST /search Ricerca prodotti eBay con ranking multi-fattore
POST /parse Parser query → brand, prezzo, condizione, categoria
GET /seller/{name} Trust score, feedback samples e metriche venditore
GET /wishlist Lista oggetti salvati dell'utente autenticato
POST /wishlist Aggiunge item alla wishlist + sync eBay watchlist
DELETE /wishlist/{ebay_id} Rimuove item da wishlist e da eBay watchlist
POST /auth/register Creazione account utente con password hash
POST /auth/login Login → JWT access token + refresh token
GET /health Health check sistema
